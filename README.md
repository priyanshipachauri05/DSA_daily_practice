# DSA Daily Practice Problem

This repository consists of some problems I encountered while studying Data Structure and Algorithms (DSA). These problems helped me to develop my analytical thinking and problem-solving skills.

For each problem, I tried to follow a structed approach. I begin with the brute-force solution, analyse its time complexity and limitations, and explore the improvements before moving towards an optimal approach.

This methodology helped me improve my thinking methodology while encountering such type of problems.

At the end of the solution file of each problem, I have also added some more problems that follow the same approaches. This helps me identify recurring patterns in DSA problems.
